현재 페이지는 전체 디자인 방향은 좋아졌지만 PC와 모바일 모두에서 섹션 간 여백이 다소 넓고, placeholder 이미지가 실제 콘텐츠보다 큰 비중을 차지해 페이지가 길게 느껴집니다. 제품 이미지가 아직 들어가지 않은 상태라 어느 정도 여백이 많아 보이는 것은 정상입니다. 하지만 지금 단계에서도 공식 제품 홈페이지처럼 보이도록 정보 밀도를 조금 더 높여야 합니다.

중요:
1. 전체 디자인을 새로 만들지 마세요.

────────────────────────────────
1. 전체 여백 조정
────────────────────────────────

현재 섹션 간 vertical padding이 너무 넓게 느껴집니다. 아래 기준으로 조정해 주세요.

PC 기준:
- 각 section의 상하 padding을 현재보다 약 15~25% 줄입니다.
- Hero 섹션은 너무 압축하지 말고 현재보다 약 10~15%만 줄입니다.
- 섹션 제목과 본문 사이 간격은 유지하되, 제목 블록과 카드/이미지 영역 사이의 간격은 약간 줄입니다.
- 카드 grid의 row-gap은 현재보다 10~20% 줄입니다.

모바일 기준:
- 각 section의 상하 padding을 현재보다 약 25~35% 줄입니다.
- 카드 사이 gap을 줄이되, 터치 가독성이 떨어지지 않게 합니다.
- H2와 본문 사이 간격은 너무 붙이지 말고 유지합니다.
- 본문 아래 카드가 시작되기 전 여백은 줄입니다.

권장 CSS 변수 예시:
- --section-py-desktop: 96px 이하
- --section-py-tablet: 72px 이하
- --section-py-mobile: 48px 이하

이미 CSS 변수 구조가 없다면 :root에 spacing 변수로 정리해 주세요.

2. Hero 영역 밀도 조정
────────────────────────────────

Hero는 현재 방향이 좋으므로 구조는 유지합니다.
다만 PC에서 Hero의 위아래 여백이 다소 큰 느낌이 있으므로 다음처럼 조정해 주세요.

PC:
- Hero 전체 높이를 과하게 크게 잡지 않습니다.
- 좌측 텍스트와 우측 이미지의 세로 중앙 정렬은 유지합니다.
- 스펙 카드 4개는 너무 넓게 퍼지지 않게 compact하게 정리합니다.

모바일:
- 첫 화면에서 최소한 H1, CTA, 핵심 스펙 일부가 보이도록 합니다.
- Hero 이미지 placeholder가 모바일에서 너무 큰 경우 10~20% 줄입니다.
- 모바일 Hero 순서는 유지합니다: 라벨 → H1 → 본문 → CTA → 스펙 카드 → 이미지.

다만 카드 높이와 간격이 조금 길게 느껴질 수 있으므로 다음처럼 조정해 주세요.
